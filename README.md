# CUBO

A dashboard-style bento grid landing page for a fictional digital design studio called Cubo. Built to practice packing analytics-style stats and content into a bento layout, not a real company.

## About

This one leans into the "dashboard meets landing page" style — stat cards (project views, new users, engagement rate), a growth chart, a font showcase, and a services callout, all arranged as uneven bento grid tiles around a central portrait image.

## Built with

- HTML
- CSS (CSS Grid for the bento layout)

No frameworks, just plain HTML and CSS.

## Features

- Circular progress card ("Brand of Designing" 75% progress)
- Stat cards for project views, new users, and daily new clients, each with a growth percentage
- Central photo card with overlapping mini-cards (Project Growth chart, Conversion Age bar chart, Engagement Rate)
- Team avatars row ("Team of passionate designers and developers")
- "Smart Digital Agency" callout card with two supporting images
- Font showcase card with a color palette
- "We Build Future of Design Industry" CTA card
- Brand/studio identity card with a "Discover more" button

## Running it locally

```bash
git clone https://github.com/shivamsingh-net/CUBO.git
cd CUBO
```

Just open `index.html` in your browser after that. Nothing else needed.

## What I was practicing

- Building a dense, dashboard-style bento grid with CSS Grid
- Designing cards that mix charts, stats, photos, and text in the same visual system
- Layering smaller "floating" cards over a larger photo card
- Keeping a busy layout readable through consistent spacing and a limited color palette (pink/black/white)
